SONOTYPE STUDIO — GIANX LABS

Lightweight static music experiment.
No npm, React, backend, samples or external libraries required.

FEATURES
- Text / numbers / symbols generate deterministic melody, chords and beat
- Key, major/minor scale, BPM and composition length
- Separate melody/chord sound choices
- Synthesized kick, snare and hi-hat
- Click-to-edit 16-step beat sequencer
- Looping live playback
- MIDI export (melody, chords, drums on separate MIDI channels)
- WAV export with selectable 1 / 2 / 4 / 8 / 16 loops

DEPLOY TO NETLIFY
1. Unzip sonotype-studio.zip
2. In Netlify choose Add new project > Deploy manually
3. Drag the sonotype-studio folder into Netlify

Open index.html locally in a modern browser to test it.
